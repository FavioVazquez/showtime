# Out of scope

Requests showtime has decided not to take, each with the reason. Link the relevant file when closing an
issue or declining a pull request, so the discussion does not start from zero each time. A decision can
be revisited: open an issue that answers the reason given here.

| File | Decision |
|---|---|
| [cloud-apis.md](cloud-apis.md) | No cloud AI or media APIs, API keys or accounts |
| [uploading.md](uploading.md) | showtime never uploads or publishes anything |
| [non-commercial-assets.md](non-commercial-assets.md) | No non-commercial assets or models by default |
| [required-gpu.md](required-gpu.md) | A GPU is never required |
| [avatars.md](avatars.md) | No talking avatars or cloned faces |
