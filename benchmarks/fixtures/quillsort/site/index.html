quillsort

Sort, dedupe and tidy the lines of any text file.

Get quillsort 2.0 
$ quillsort files.txt --natural --unique
file1.txt
file2.txt
file10.txt
  • Natural sort: file2 before file10
  • In-place edits with an automatic .bak backup
  • Duplicate removal that keeps the first occurrence
  • One Python file, no dependencies

Install

pip install quillsort
