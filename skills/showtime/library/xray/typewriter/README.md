# Typewriter (manual, front-strike)

Parts: key levers, the typebar segment (a fan of typebars), the print point on the platen, the ribbon and its
spools, the escapement star wheel and carriage rack, the mainspring, the carriage return lever.

- An event = a keystroke: the key goes down and its typebar swings up to the print point, peaking on the
  event's frame; the ribbon lifts; the escapement lets the carriage step one letter on that frame.
- `"kinds": {"<i>": "return"}`: a carriage return winds the mainspring back.
- Which key: only from evidence, `"text"` (what the paper shows, one character per keystroke). Without it a
  keystroke lights the typebar fan, never a guessed key.
- Anchors to place on the reference frame: `key_q`, `key_p`, `key_m` (key centres) and `print_point`.
- Measured: keystroke times and count (the clip's sound), the text (the paper). Drawn: a generic manual
  typewriter, not this exact machine.

Verified on: Underwood 315 portable (Erik Pålsson / Sounds of Changes, CC BY 3.0: https://commons.wikimedia.org/wiki/File:Underwood_315_portable_typewriter.webm), 18 of 18 keystrokes on
their frame.
